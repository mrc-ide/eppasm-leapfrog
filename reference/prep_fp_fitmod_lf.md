# Prepare leapfrog inputs object for fitting and prepare likelihood data

Prepare leapfrog inputs object for fitting and prepare likelihood data

## Usage

``` r
prep_fp_fitmod_lf(params, eppd, epp_t0, ...)
```

## Arguments

- params:

  Leapfrog input data

- eppd:

  EPP input data

- ...:

  Additional parameters to set/override on \`params\`

## Value

List containing \`fp\` object ready for fitting and likelihood data
\`likdat\`
